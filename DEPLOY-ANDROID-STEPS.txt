CYBERSID - GO LIVE ON ANDROID
Do the parts in order. Tick each line. If anything shows red text, stop and send it to Claude.
Project folder: C:\Projects\cybershorts

WHAT LIVES WHERE (nothing is moving off your PC)
  Your PC + VS Code : where you edit and test. The master copy stays here.
  GitHub            : an online copy of the code. It also runs the news robot every hour for free,
                      so your PC can be switched off.
  Supabase          : the database in the cloud. The robot saves news here, the app reads it.
  Expo (EAS)        : builds the real Android app file in the cloud.
  Google Play       : gets the app to people's phones.
  When you change code on your PC: git add . / git commit / git push  -> GitHub gets the new copy.

PART 1 - INSTALL THE CYBERSID UPDATE (20 min)
=====================================================================
[ ] 1.1  Save cybershorts-cybersid-v3.zip to D:\Cyber Security, then in PowerShell:
         Expand-Archive "D:\Cyber Security\cybershorts-cybersid-v3.zip" -DestinationPath "C:\Projects\cybershorts" -Force
[ ] 1.2  In app\.env change the last line to:  EXPO_PUBLIC_SOURCE_IMAGES=true
[ ] 1.3  cd C:\Projects\cybershorts\app
         npm install
         npx expo start -c
         Check: CyberSid logo in the header, blue colours, new font, article photos with "Image: <site>", new chain screen.
[ ] 1.4  AI pictures, part 1 (the picture folder). Supabase > SQL Editor > New query.
         Open pipeline\update_all.sql in VS Code, copy ALL of it, paste, Run. Should say "Success".
[ ] 1.5  AI pictures, part 2 (free Cloudflare key, about 150 pictures a day):
         dash.cloudflare.com > sign up free (use the app Gmail) > left menu "AI" > "Workers AI"
         > "Use REST API" > copy the Account ID > click "Create a Workers AI API Token" > Create > copy the token.
         Add 2 lines to the ROOT .env (C:\Projects\cybershorts\.env, NOT app\.env):
           CF_ACCOUNT_ID=paste_account_id
           CF_API_TOKEN=paste_token
         (Skip this and it still works with the free no-key service, just slower.)
[ ] 1.6  cd C:\Projects\cybershorts\pipeline
         pip install -r requirements.txt
         $env:COVERS_BACKFILL=3; python pipeline.py --covers
         Should end with "Made 3 pictures". Reload the app: those cards now have a picture marked "AI illustration".
         Then give all recent cards a picture:   $env:COVERS_BACKFILL=40; python pipeline.py --covers

PART 2 - MAKE GITHUB PUBLIC SAFELY (10 min)
=====================================================================

           git log -p --all | Select-String -Pattern 'sb_secret_\w{10}|AIza[\w-]{20}|gsk_\w{20}|csk-\w{20}|sk-ant-[\w-]{20}'
         Nothing should print. If ANYTHING prints, STOP and tell Claude (keys must be changed first).

           git add .
           git commit -m "CyberSid: branding, article images, new chain screen, privacy policy"
           git push
[ ] 2.6  repo > Settings > General > scroll to "Danger Zone" > Change visibility > Public > confirm
[ ] 2.7  Privacy policy website (free): repo > Settings > Pages >

         After 1-2 minutes your policy is at:  https://YOUR-GITHUB-NAME.github.io/cybershorts/
         Open docs\index.html in VS Code first and replace REPLACE_WITH_APP_GMAIL (2 places) with the app Gmail, then push again.

PART 4 - BUILD THE REAL ANDROID APP (30 min, mostly waiting)
=====================================================================
[ ] 4.1  cd C:\Projects\cybershorts\app
[ ] 4.2  npx eas-cli@latest login          (use your Expo account)
[ ] 4.3  npx eas-cli@latest init           (answer Yes to create the project)
         Note: the Android ID is app.cybersid.news. Once the app is on Google Play this can never change.
[ ] 4.4  Open app\eas.json in VS Code. In BOTH "preview" and "production" replace:
           PASTE_SUPABASE_URL      with your Supabase URL
           PASTE_PUBLISHABLE_KEY   with the sb_publishable_ key (NEVER the secret key)
         Save.
[ ] 4.5  Test build (an .apk you can install directly):
           npx eas-cli@latest build -p android --profile preview
         Say Yes when it offers to create an Android keystore (Expo keeps it safe for you).
         When done (10-20 min) it shows a link / QR code. Open it on your phone and install.
[ ] 4.6  Test the installed app (not Expo Go) for a day. Send Claude anything odd.

           Data safety: No user data collected or shared (see privacy policy)
           Government app: No    Financial features: None    Health: No
[ ] 5.4  Store listing (Grow > Store presence > Main store listing):
